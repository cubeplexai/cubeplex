# CubePlex 0.9.2

## 修复

- **IM 消息可以再次触发 Agent 回复。** 模型选择不一致可能导致通过 IM 连接器收到的消息在 Agent 开始回复前被拒绝。现在会使用消息入队时的原始模型选择启动运行。

## 升级前须知

请将后端、前端和 sandbox 镜像一起升级到 `v0.9.2`，或安装 `0.9.2` 版本的 Helm chart。除常规镜像版本更新外，本次发布没有新增数据库迁移或配置变更。

如果组织保存过[沙箱策略](../admin/sandbox.md)，请将其中的默认镜像更新为 `ghcr.io/cubeplexai/cubeplex-sandbox:v0.9.2`。保存的策略优先于部署配置。正在运行的 sandbox 会继续使用原镜像，待任务结束后重启才会更换。
