# CubePlex 0.9.1

## 修复

- **PDF 预览可以可靠加载。** 预览现在会打包与 PDF 库匹配的 worker，避免 worker 版本不一致导致加载失败。

## 升级前须知

请将后端、前端和 sandbox 镜像一起升级到 `v0.9.1`，或安装 `0.9.1` 版本的 Helm chart。除常规镜像版本更新外，本次发布没有新增数据库迁移或配置变更。

如果组织保存过[沙箱策略](../admin/sandbox.md)，请将其中的默认镜像更新为 `ghcr.io/cubeplexai/cubeplex-sandbox:v0.9.1`。保存的策略优先于部署配置。正在运行的 sandbox 会继续使用原镜像，待任务结束后重启才会更换。
