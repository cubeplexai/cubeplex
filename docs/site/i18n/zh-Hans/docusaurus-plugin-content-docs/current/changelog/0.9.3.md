# CubePlex 0.9.3

## 新功能与改进

- **Markdown 预览支持 Mermaid 图表。** 聊天消息、产物预览、技能、抓取的网页和追踪消息会将标记为 `mermaid` 的代码块渲染为适配当前主题的图表。图表不完整或语法无效时显示源码，下载仍保留原始 Markdown。参见[产物预览](../guides/conversations/artifacts.md)。
- **后端提供 Prometheus 运行指标。** `/metrics` 暴露 HTTP 与 SSE 活动、Agent 运行结果、LLM 调用与 token 用量，以及工具调用结果。在 Prometheus 中配置后，可通过 Docker Compose 标签和 Kubernetes Pod 注解进行发现。参见[指标列表与统计规则](../deployment/overview.md#metrics)。
- **写入文件时更早显示预览。** 文件内容仍在生成时，就可以看到 write 工具行及其预览。多个文件同时写入时，其他调用更新或完成不会切换你选中的文件。
- **对话刷新保留阅读状态。** 对话没有变化时，不再重复下载历史或重新挂载消息卡片。标签页隐藏时暂停检查，返回后恢复。

## 修复

- **子 Agent 命令执行更可靠。** 子 Agent 的 shell 命令保持前台运行，持续展示进度，并返回有长度限制的结果或超时状态。临时轮询失败会重试，但不会重放启动结果不确定的命令；命令记录缺失和执行服务失败会明确报告。临近截止时间完成的输出也会保留。参见[沙箱命令行为](../guides/conversations/sandboxes.md#后台命令与结果恢复)。
- **聊天中展示原始图片。** 展示的图片加载原文件，按解码后的真实比例显示，并在需要时才加载。点击图片可打开原图；加载失败时可下载文件。
- **隐藏内部后台任务载荷。** 原始任务投递输入不再出现在活跃流式对话或后台任务列表中。
- **图表旁的引用保持可见。** 渲染 Mermaid 不再丢失周围 Markdown 中的引用。
- **关闭期间的日志更清晰。** 因 Uvicorn 优雅关闭超时而取消的 HTTP 请求和 SSE 流，其预期取消异常以 INFO 记录且不带堆栈。强制关闭汇总仍为 ERROR，其他取消和应用错误保持原有报告方式。

## 升级前须知

请将后端、前端和 sandbox 镜像一起升级到 `v0.9.3`，或安装 `0.9.3` 版本的 Helm chart。除常规镜像版本更新外，本次发布没有新增数据库迁移或必需的配置变更。

如果组织保存过[沙箱策略](../admin/sandbox.md)，请将其中的默认镜像更新为 `ghcr.io/cubeplexai/cubeplex-sandbox:v0.9.3`。保存的策略优先于部署配置。正在运行的 sandbox 会继续使用原镜像，待任务结束后重启才会更换。

新增的 `/metrics` 端点没有应用层认证。请仅允许监控网络访问，或在代理、防火墙中限制访问。需配置 Prometheus 分别抓取每个后端实例；仅添加部署标签和注解不会启用抓取。参见 [Docker Compose](../deployment/docker-compose.md#prometheus-metrics) 和 [Kubernetes](../deployment/kubernetes.md) 指南。
