# CubePlex 0.9.5

## 新功能与改进

- **面向邮箱的组织邀请。** 组织管理员可以在[成员管理](../admin/members.md)页面按邮箱发送邀请。被邀请人只有在接受邀请链接后才会成为组织成员。
- **话题上下文与发送者归属。** Agent 现在会感知当前话题标题作为对话上下文，[话题](../guides/conversations/topics.md)消息也会显示发送者归属。
- **置顶对话任务列表。** Agent 的任务计划现在以单个可折叠长条固定在输入框上方，不再在每条助手消息上重复显示。
- **轮次导航栏。** 宽屏对话左侧边缘新增轮次导航栏，支持悬停预览、点击滚动定位，以及顶部加载更早历史记录。
- **用户消息支持 Markdown 与数学公式。** 用户消息现在会渲染 Markdown 和数学公式，同时保留货币金额格式。
- **模型品牌图标与默认推理强度。** 新增 Google Gemini、Meta Llama、Cohere、混元、文心、星火、Yi、InternLM、Microsoft、SiliconCloud 和 Azure 品牌图标；推理模型默认思考强度调整为 `medium`；前端按需懒加载 KaTeX、对话框和非默认图标以加快启动。
- **更快的沙箱执行与运行时升级。** 消除了沙箱每次执行命令时的 1 秒 SSE 等待，将 OpenSandbox SDK 与内置 Helm chart 升级至 `1.1.1`，将 CubeLoop 更新至 `0.16.1`，并刷新了 `models.dev` 目录快照。

## 修复

- **`/compact` 执行与等待提示。** `/compact` 现在通过 CubeLoop 的 `compact_history` 并使用配置的压缩模型执行，同时在运行期间显示等待提示。
- **MCP 1.x / 2.x 兼容与 Asana OAuth。** 通过 CubeLoop 的自动模式 `Client` 路由 MCP 发现、工具缓存与 Try It，同时兼容 MCP 1.x 和 2.x 服务器；并将 Asana 配置为静态 OAuth 客户端而非动态注册。
- **群聊与账号头像。** 修复了[群聊](../guides/conversations/group-chats.md)中发送者头像不匹配的问题，为话题参与者补充了 `avatar_style`，并在 Google 登录时保留邮箱账号原有头像。
- **对话历史、故障转移与停止状态。** 修复了历史记录中已投递后台任务结果的展示，将故障转移横幅锚定到原始轮次，停止运行后显示**已停止**标记，默认折叠刷新后的工具活动与恢复的任务列表，并隐藏正在流式输出检查点上的悬停操作栏。
- **组织邀请与侧边栏导航。** 修复了组织成员邀请向已移除路由发起请求的问题，并为侧边栏对话点击未触发跳转的情况增加了回退处理。
- **产物展示。** 禁止在 `save_artifact` 之后重复调用 `present_file`。

## 升级前须知

请将后端、前端和 sandbox 镜像一起升级到 `v0.9.5`，或安装 `0.9.5` 版本的 Helm chart。常规迁移步骤会为 `org_invite_tokens` 表增加可空的 `email` 列。Docker Compose 的 `backend-migrate` 服务和 Kubernetes 升级任务会自动执行该变更。

如果使用 Helm 或 Docker Compose 部署，请确保 OpenSandbox 运行时版本与 [Kubernetes](../deployment/kubernetes.md) 和 [Docker Compose](../deployment/docker-compose.md) 部署指南中的 `release-1.1.1` 保持一致。

如果组织保存过[沙箱策略](../admin/sandbox.md)，请将其中的默认镜像更新为 `ghcr.io/cubeplexai/cubeplex-sandbox:v0.9.5`。保存的策略优先于部署配置。正在运行的 sandbox 会继续使用原镜像，待任务结束后重启才会更换。
