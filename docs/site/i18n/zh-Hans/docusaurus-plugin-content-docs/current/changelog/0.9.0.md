# CubePlex 0.9.0

长时间运行的命令现在可以在当前回复结束后继续作为后台任务执行。你可以在对话中查看进度和输出、停止单个任务，并让 Agent 在结果就绪后继续处理请求。

## 升级前须知

从 0.8.0 升级的已有部署需要执行一次维护迁移，将命令历史和待发送的结果通知迁移到新的任务生命周期。执行前必须停止所有旧版后端 API 和 worker；这次迁移不能在滚动升级中与旧版后端实例同时运行。全新安装仍使用正常安装流程。

具体操作见 [Docker Compose](../deployment/docker-compose.md#upgrading-a-database-from-before-the-task-lifecycle-cutover) 或 [Kubernetes](../deployment/kubernetes.md#upgrading-a-database-from-before-the-task-lifecycle-cutover) 的维护升级步骤。迁移器报告仍在运行的旧命令或监控任务时，需等待它们结束或明确停止后再重试。迁移不会把无法访问的进程当作已结束。

请将后端、前端和 sandbox 镜像一起升级到 `v0.9.0`，或安装 `0.9.0` 版本的 Helm chart。

## 后台任务

- **长命令可以跨回复运行。** 支持后台执行的命令在运行超过 60 秒后，会转为对话的后台任务。Agent 可以结束当前回复，在最终结果到达后继续处理请求。执行任务默认有一小时的截止时间。
- **任务完成后继续对话。** 任务结果先被持久化，再投递给 Agent，触发后续回复。在群组对话中，如果其他参与者正在使用当前运行，或有待确认的问题，结果会等待投递。
- **监控任务只报告一次最终结果。** 监控任务检查一个条件，最终报告成功、失败或超时；日志输出不会反复唤醒 Agent。停止监控任务不会停止它观察的其他命令或服务。

任务行为和恢复说明见[管理沙箱](../guides/conversations/sandboxes.md#后台命令与结果恢复)。

## 任务控制与输出

- **独立的任务面板。** 从对话顶部打开“后台任务”，查看正在运行和最近完成的任务。按钮角标显示未完成的任务数。
- **停止单个任务或当前全部工作。** “停止任务”针对一个任务；“全部停止”会停止当前回复和当前执行批次中的任务。请求被接受后，状态保持“停止中”，直到确认执行已终止。
- **在预览面板中查看结果。** 已完成任务以紧凑条目显示在对话时间线中。点击后，在右侧预览面板查看执行记录、请求和最终输出；移动端使用全屏预览。
- **命令输出实时显示。** 命令运行期间即可看到输出。命令详情将 shell 命令与执行选项分开显示，支持复制命令，以及展开和复制原始请求 JSON。

## 可靠性改进与修复

- 改进 worker 中断后对已接受消息、定时任务、事件触发任务和后台结果通知的恢复。
- 改进命令最终日志的恢复。进程退出后，如果输出仍在恢复，任务会保持结果待就绪；无法获取的输出会被明确标识，不会显示为完整结果。
- 重启或删除 sandbox 时，会请求停止其中的任务，并等待确认清理完成。资源删除或访问权限移除也会撤销相关工作。
- 允许文本输入的交互提问现在能接受自定义回答，包括通过 IM 连接器发送的后续问题。飞书回执会保留提交的自定义回答。
- 修复首次设置组织时的重复跳转、展示图片尺寸过大，以及同一次运行中多轮重复显示“回复失败”的问题。
- sandbox 镜像新增 OpenSSH 客户端，可直接使用 `ssh` 和 `scp`。
