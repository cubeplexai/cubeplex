# 连接企业微信智能机器人

CubePlex 通过出站 WebSocket 连接企业微信智能机器人，不需要配置公网回调地址，但 API
服务必须能通过 443 端口访问 `wss://openws.work.weixin.qq.com`。

## 创建机器人

1. 在企业微信桌面端打开 **工作台 → 智能机器人 → 创建 → 手动创建**。
2. 选择 **API 模式创建**，连接方式选择 **使用长连接**。
3. 复制机器人的显示名称和 **Bot ID**，再获取并复制 **Secret**。请安全保存 Secret；企业微信
   可能只显示一次。
4. 保存机器人。

![企业微信智能机器人 API 模式凭据页面占位图](/img/im/wecom-api-mode-placeholder.svg)

## 绑定到 CubePlex

1. 打开 **Workspace 设置 → IM**，选择 **连接 → 企业微信**。
2. 完成前置条件检查。
3. 输入 Bot ID、与企业微信中完全一致的机器人显示名称和 Secret，然后点击 **连接**。
   CubePlex 使用显示名称移除群消息开头的 @ 提及，也支持名称中包含空格的机器人。

CubePlex 会先验证凭据，再加密保存；绑定成功后立即建立长连接。一个机器人只允许一个活跃
客户端。若其他产品连接了同一机器人，CubePlex 可能被断开。请先停止冲突客户端，再在
CubePlex 中禁用并重新启用该账号。

## 关联身份

企业微信回调不提供邮箱。首次运行智能体前，请向机器人发送：

```text
/link you@example.com
```

登录 CubePlex 后打开机器人返回的链接。该邮箱必须属于机器人所在 Workspace 的当前成员；
CubePlex 会在每条消息到达时重新检查成员资格。

## 使用机器人

- 私聊中可直接发送消息。
- 群聊中需要 @ 机器人。账号的群聊路由设置决定每位成员使用隔离会话，还是全群共享一个会话。
- 发送 `/new`、`/reset` 或 `新对话`，可为当前范围开始新会话。
- 发送 `/stop`，可终止当前正在进行的回复（不会清空已排队的后续消息）。
- 发送 `/steer <消息>`，可向当前正在进行的回复中途补充指令（若当前无活跃回复，则直接作为新消息发送）。
- 发送 `/models`，可列出可用的模型预设并查看当前会话正在使用的预设。
- 发送 `/model <名称>`，可切换当前会话后续消息使用的模型预设。

回复窗口有效时，结果会在原消息中流式显示；耗时较长或延迟执行的任务会改为主动发送最终结果。

在**私聊**中发送的图片、文件和视频会下载、解密，并按网页上传同样的方式交给 agent。群聊里的
图文混排消息也可以带上图片。语音消息仍然只使用企业微信提供的转写文本。

当 agent 展示文件（`present_file`）或保存交付物（`save_artifact`）时，CubePlex 会通过机器人
连接上传，并发送企业微信原生的图片或文件消息。超过 20 MB 或上传失败时回退为分享链接。入站
下载链接五分钟过期；如果机器人正忙于另一个任务、超过这个窗口，文件会被跳过，并告知 agent
该附件已忽略。

## 轮换凭据

在 CubePlex 中删除企业微信账号，在企业微信中生成或复制当前 Secret，然后重新连接。
禁用会立即关闭连接；重新启用会自动建立连接，无需重启 API。

## 当前限制

当前仅支持企业微信智能机器人，不支持个人微信、企业应用回调模式、扫码配置，也不支持在企业
微信内直接完成审批或问答交互。遇到等待输入时，请前往 CubePlex Web UI 继续操作。企业微信
本身只在私聊中投递独立的图片、文件和视频回调。
