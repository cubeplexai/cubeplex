# CubePlex 0.9.5

## Features and improvements

- **Address organization invitations to an email.** Organization admins can invite members by email from the [Members](../admin/members.md) page. An invitee becomes an organization member only after accepting the invitation link.
- **Topic context and sender attribution.** Agents now receive the current topic title as conversation context, and [topics](../guides/conversations/topics.md) display sender attribution on messages.
- **Pinned conversation task list.** The agent's task plan now appears as a single collapsible strip above the composer instead of repeating on every assistant message.
- **Turn navigation rail.** Wide conversations show a turn navigation rail along the left edge with hover previews, click-to-scroll, and a top control to load older history.
- **Markdown and math in user messages.** User messages now render Markdown and math formulas while preserving currency amounts.
- **Model brand icons and default reasoning effort.** Added brand icons for Google Gemini, Meta Llama, Cohere, Hunyuan, Wenxin, Spark, Yi, InternLM, Microsoft, SiliconCloud, and Azure; reasoning models now default to `medium` thinking level; and the frontend lazy-loads KaTeX, dialogs, and non-default icons for faster startup.
- **Faster sandbox execution and runtime upgrades.** Eliminated the 1-second per-command SSE wait in sandboxes, upgraded OpenSandbox SDK and vendored Helm charts to `1.1.1`, updated CubeLoop to `0.16.1`, and refreshed the `models.dev` catalog snapshot.

## Fixes

- **`/compact` execution and waiting state.** `/compact` now invokes CubeLoop's `compact_history` with the configured compaction model and shows a waiting line while running.
- **MCP 1.x / 2.x and Asana OAuth.** Routed MCP discovery, tool caching, and Try It through CubeLoop's auto-mode `Client` to support both MCP 1.x and 2.x servers, and configured Asana as a static OAuth client instead of dynamic client registration.
- **Group chat and account avatars.** Fixed sender avatar mismatches in [group chats](../guides/conversations/group-chats.md), included `avatar_style` on topic participants, and preserved email-account avatars on Google login.
- **Conversation history, failover, and stop indicators.** Restored delivered background task results in history, anchored failover banners to their originating turn, displayed a **Stopped** chip after stopping a run, kept tool activity and restored task lists collapsed by default, and suppressed hover actions on active streaming checkpoints.
- **Organization invites and sidebar navigation.** Fixed organization member invites posting to a removed route, and added a navigation fallback when a sidebar conversation click does not navigate.
- **Artifacts.** Disallowed duplicate `present_file` calls after `save_artifact`.

## Before upgrading

Upgrade the backend, frontend, and sandbox image together to `v0.9.5`, or install Helm chart `0.9.5`. The normal migration step adds a nullable `email` column to `org_invite_tokens`. Docker Compose `backend-migrate` and the Kubernetes upgrade job apply this change automatically.

If you deploy with Helm or Docker Compose, ensure your OpenSandbox runtime matches the `release-1.1.1` pins in the [Kubernetes](../deployment/kubernetes.md) and [Docker Compose](../deployment/docker-compose.md) deployment guides.

If your organization has a saved [sandbox policy](../admin/sandbox.md), update its default image to `ghcr.io/cubeplexai/cubeplex-sandbox:v0.9.5`. The saved policy takes precedence over the deployment setting. Existing running sandboxes keep their current image until restarted after their tasks finish.
