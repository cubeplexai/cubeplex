# CubePlex 0.9.1

## Fixes

- **PDF previews load reliably.** The preview now bundles the PDF worker that matches its PDF library, avoiding failures caused by a worker version mismatch.

## Before upgrading

Upgrade the backend, frontend, and sandbox image together to `v0.9.1`, or install Helm chart `0.9.1`. This release adds no database migration or configuration change beyond the normal image version update.

If your organization has a saved [sandbox policy](../admin/sandbox.md), update its default image to `ghcr.io/cubeplexai/cubeplex-sandbox:v0.9.1`. The saved policy takes precedence over the deployment setting. Existing running sandboxes keep their current image until restarted after their tasks finish.
