# CubePlex 0.9.2

## Fixes

- **IM messages start agent responses again.** A model selection mismatch could reject incoming messages from IM connectors before the agent began responding. The admitted message is now replayed with its original model selection.

## Before upgrading

Upgrade the backend, frontend, and sandbox image together to `v0.9.2`, or install Helm chart `0.9.2`. This release adds no database migration or configuration change beyond the normal image version update.

If your organization has a saved [sandbox policy](../admin/sandbox.md), update its default image to `ghcr.io/cubeplexai/cubeplex-sandbox:v0.9.2`. The saved policy takes precedence over the deployment setting. Existing running sandboxes keep their current image until restarted after their tasks finish.
